# Zepto-Inventory-Analysis-using-Excel-Visualization-From-SQL
# Zepto Inventory Analysis using Excel Visualization

## Project Overview

This project focuses on analyzing the **Zepto Inventory Dataset** using **Excel-based data analysis and visualization techniques** to generate meaningful business insights. The analysis helps understand pricing strategies, discounts, category performance, inventory distribution, and product value.

The project demonstrates practical skills in:

* Data Analysis
* Data Cleaning
* Excel Dashboard Creation
* Business Intelligence
* Data Visualization

---

# Dataset Information

Dataset Used: `ZEPTO.csv`

### Main Attributes

* Product Name
* Category
* MRP
* Discount Percentage
* Discounted Selling Price
* Available Quantity
* Product Weight
* Stock Availability

# Business Problems Solved

## 1. Top 10 Best Valued Products Based on Discount Percentage

Analyzed products with the highest discount percentages to identify the best deals available for customers.

### Visualization Used

* Horizontal Bar Chart
* Top Discount Products Dashboard

---

## 2. Estimated Revenue for Each Category

Calculated category-wise estimated revenue using product price and available inventory quantity.

### Visualization Used

* Pie Chart
* Revenue Contribution Dashboard

---

## 3. Products with High MRP and Low Discount

Identified premium products priced above ₹500 with discount percentages lower than 10%.

### Visualization Used

* Product Comparison Table
* High Value Product Dashboard

---

## 4. Top 5 Categories with Highest Average Discount

Analyzed categories offering the highest average discounts to customers.

### Visualization Used

* Column Chart
* Category Discount Analysis

---

## 5. Price Per Gram Analysis

Compared products based on price per gram to identify the best value-for-money products.

### Visualization Used

* Scatter Plot
* Best Value Product Analysis

---

## 6. Product Segmentation into Low, Medium, and Bulk

Grouped products based on weight into:

* Low
* Medium
* Bulk

### Visualization Used

* Pie Chart
* Product Size Distribution Dashboard

---

## 7. Total Inventory Weight Per Category

Calculated total inventory weight available for each category.

### Visualization Used

* Stacked Bar Chart
* Inventory Weight Analysis
